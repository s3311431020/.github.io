四種排序演算法：誰比較快？

使用同一組最多 99 個數值，分別用 氣泡排序 (Bubble)、插入排序 (Insertion)、 選擇排序 (Selection) 與 快速排序 (Quick) 排序，觀察它們的比較次數、交換次數與實際執行時間。

  • 可用亂數產生 99 個數值，或貼上題目給你的數字。
  • 程式會自動幫你算出四種演算法的統計數據，方便填入「分析判斷表」。
  • 右邊抽獎機會顯示「快速排序」結果的前幾顆球，增加遊戲感。
排序抽獎機

1. 準備資料 建議：99 個數值

可以用亂數產生 99 個數值，或自行貼上題目給的資料（用逗號、空白或換行分隔）。

目前共有 0 個數值。

2. 執行四種排序並觀察差異

按下按鈕後，會對同一組資料分別做 Bubble / Insertion / Selection / Quick 排序，並統計比較次數與執行時間。

提醒：這裡的「比較次數」指的是進行 if (a > b) 類判斷的次數；「交換次數」則是兩個數值互換位置的次數。
氣泡排序 (Bubble Sort) 一直交換相鄰元素
插入排序 (Insertion Sort) 像玩撲克牌插入適當位置
選擇排序 (Selection Sort) 每一輪選出最小值
快速排序 (Quick Sort) 分治法：選 pivot 分左右兩邊
