程式練習專區

每週上課做的小專題、小工具，會集中放在這裡，讓學生回家可以重複操作與修改程式碼。

  • 打散程式練習（洗牌 + 抽中 3 位數字 + 最大值）
    輸入 1 ~ n 的整數範圍，使用 Fisher-Yates 洗牌演算法打散順序， 再抽出 3 位中獎號碼，並找出最大值及其在陣列中的位置。 練習重點：for 迴圈、陣列、Math.random()、最大值搜尋。
  • 打散 + 排序法練習
    輸入一串任意數字，先做「打散」，再顯示「由小到大」與「由大到小」排序結果。 練習重點：字串切割、陣列複製、Fisher-Yates 洗牌、Array.sort() 比較函式。
  • 四種排序演算法比較（Bubble / Insertion / Selection / Quick）
    自動產生或輸入最多 99 個數值，一次比較四種排序演算法的執行時間、比較次數與交換次數。 練習重點：時間複雜度 Big-O 概念與不同演算法的效能差異。
  • 來玩終極密碼遊戲（用二元搜尋找答案）
    電腦在一個範圍內選一個秘密數字，你要用最少次數把它找出來。 搭配抽獎機視窗顯示 low / mid / high 三顆球，幫助理解 Binary Search 的範圍縮小過程。 練習重點：二元搜尋的思考方式、猜中間 vs 亂猜的差異。
  • jQuery 打招呼小程式（Hello!! 你好）
    輸入訪客的姓名，按下按鈕後，用 jQuery 讀取輸入框內容， 在可愛的對話框中顯示「Hello!! 你好」，練習 jQuery 的 click 事件與 .val() / .html() 的用法。
  • 之後每週上課完成的專題（例如：成績計算器、樂透號碼產生器、小小計時器…）都會陸續新增在這裡。

學習地圖

建議的學習順序，可以依照階段自由往前或往後跳，但先把基礎打穩最重要。

  • 階段一：HTML & 網頁基礎
    了解網頁是怎麼組成的、常見標籤、超連結、圖片與表單等。 完整版請看 HTML 基礎課程頁。
  • 階段二：CSS & RWD 版型
    學會調整字體、顏色、排版，並透過 RWD 讓網站在手機與電腦都好看。 完整版請看 CSS & RWD 課程頁。
  • 階段三：JavaScript 核心語法
    變數、條件、迴圈、陣列、函式、Canvas、JSON、爬蟲示範與 Node.js 概念。 → 已整理於 js-course.html。
  • 階段四：進階主題 & 專題
    React 計數器、Node.js 平行運用、實作小專題（成績計算器、小小爬蟲 demo、簡易遊戲介面…）。
